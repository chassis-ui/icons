## Introduction

Chassis Icons turns the SVG files of a team into an icon font, an SVG sprite and optimized SVG files. The work is split over two kinds of repository, so that a team owns its icons and shares the build:

- **The builder.** `@chassis-ui/icons` is an npm package with the `chassis-icons` command, which optimizes the files with SVGO, builds the sprite with svg-sprite and the font with Fantasticon, and writes the stylesheets of the font. It holds no icons.
- **A repository of icons.** It holds the SVG files in `source/`, one per icon, the `chassis.build` block of its `package.json`, and the committed output. `chassis-icons init` writes one, and the builder is a development dependency of it.

The build is file-driven. Save `<name>.svg` into `source/`, and the icon is in the output of the next build: there is no list to maintain beside the files. The font name, the class prefix, the frame and the styles of the icons are settings of `chassis.build`, so the same build writes the set of any team, as [Chassis Tokens](https://chassis-ui.com/tokens) builds the tokens of any team.

The Chassis set, the icons that the Chassis documentation sites and Figma libraries use, is a repository of icons like any other: [chassis-ui/website-icons](https://github.com/chassis-ui/website-icons), published as `@chassis-ui/website-icons` and shown on this site. These pages use its names in their examples. The [quick start]([[docsref:/getting-started/quick-start]]) makes a repository of your own; the pages of [Icon Design]([[docsref:/icon-design/frame-and-color]]) say what a file needs to be an icon of a set, and those of [Use in Project]([[docsref:/use-in-project/icon-font]]) how a page draws an icon from the output.

## What a set is

A set is the icons of one repository: the SVG files of `source/`, and what the build writes from them. One repository builds one set, and `chassis-icons init` writes the files around them.

```text
source/                   -> The SVG files you save, one per icon. The build only reads them
package.json              -> The details of the package and the chassis.build configuration
svgs/                     -> Output: one optimized SVG file per icon
icons/                    -> Output: the font, its stylesheets and the sprite
codepoints.json           -> The code point of each icon. Written by the build
README.md                 -> Written by the build, for someone who installs the set
chassis.checks.json       -> The icons that consumers of the set read by name, when it has one
```

The name of a file is the name of its icon, and that name is everything a project needs to draw the icon: it is the symbol of the sprite, the last part of the class of the font, and the name of the optimized file.

## What the build writes

The build writes two folders, and their shape is the same for any set. `<font>` is the font name of the configuration, `<prefix>` its class prefix, and `<name>` the name of an icon.

<CxTable>
| File | What it holds |
| --- | --- |
| `svgs/<name>.svg` | One icon, optimized, on the frame, with `fill="currentcolor"` |
| `icons/<font>.svg` | The sprite: one `<symbol>` per icon, with the id `<name>` |
| `icons/<font>.woff2` and the other formats | The icon font |
| `icons/<font>.css`, `icons/<font>.min.css` | The font face and one class per icon, `<prefix>-<name>` |
| `icons/<font>.scss` | The same for Sass, with the folder of the font and the map of the icons as variables |
| `icons/<font>.json` | The code point of each icon, by name |
</CxTable>

The output is committed in the repository of icons and published as it is, so a project installs the set without building it. The pages of [Use in Project]([[docsref:/use-in-project/icon-font]]) show how a page draws an icon from each of these files.

## What reads a set

Chassis CSS, Chassis React and Chassis Assets take any set that keeps this shape. None of them names the Chassis set in a way that a team cannot configure.

<CxTable>
| Consumer | What it reads | Page |
| --- | --- | --- |
| Chassis CSS | An SVG file by name, through `svg-icon()` | [Chassis CSS]([[docsref:/use-in-project/chassis-css]]) |
| Chassis React | A symbol of the sprite, or a class of the font, through `Icon` | [Chassis React]([[docsref:/use-in-project/chassis-react]]) |
| Chassis Assets | The two folders of the output, renamed for iOS and Android | [iOS and Android]([[docsref:/use-in-project/ios-and-android]]) |
</CxTable>
